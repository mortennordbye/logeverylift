9. Open points

  • "Ask your coach" on a running plan. Today the AI change works only on the preview before Import. On a running plan it must change the programs in place. That is new work. The other choice is a plan card with "Change it" that opens the builder with the current plan.
  • The name. "AI coach" on the More row. A normal user may like "Coach" or "My plan" better.
  • The "building" moment (3b). About 3 seconds while the rules finish at once. Yes or no?
  • Memory for a normal user. In this draft only a connected user sees Memory. If a normal user can write notes like "sore knee", the plan builder and "Ask your coach" must read them. That is new work.
