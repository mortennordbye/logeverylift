One user, Garmin plus

The plan to merge normal and endurance users into one, with Garmin as an add-on, and to put the endurance pages behind one More row. Sources docs/plans/one-user-garmin-plus.md and docs/plans/more-endurance-hub.md.

1. From two user types to one

The endurance switch goes. Every user gets every feature from app data. Garmin is an add-on for the owner that adds richer data, and never unlocks or blocks a flow.

Today

three levels
  • Normal user: lifting, cycles, thresholds
  • Endurance user (endurance_enabled): week, player, workouts, nutrition, races
  • Garmin (garminAllowed, owner): auto-match, readiness, suggestions
→

Every user

app first, no switch
  • Lifting, cycles, seasons, races
  • Swim, bike, run as structured workouts
  • Week view, guided player, pool view, step results
  • Thresholds, athlete profile, nutrition
  • Load, limits and compliance from app data
+

Garmin plus

owner only, enriches
  • Automatic match to Garmin activities
  • Garmin load series and runs
  • Readiness from HRV and resting HR
  • Threshold suggestions, wearable nudge
  • Garmin section and widget

4. Logic that forks today

The switch also changes logic for the same data. One behaviour wins. Recommended: the endurance one, for every user.

Auto-complete of sport sessionsGoes to "Did you do it?". Moot once sport sessions are structured workouts.
log_session refuses sport programsMoot after the same conversion.
Compliance reads thresholdsBetter planned amounts when thresholds exist.
Adaptation from dated sessionsVisible change for lifters on weekday cycles. Open decision 3.
Training limits on AI writesRun for every user. A rule without data says "not checked".

5. Same app, a lifter and a triathlete

No mode switch. Four rules decide what a screen draws, so each user sees what applies to them. Source docs/plans/simple-and-power-users.md.

1. Data shows itA part draws when the user has its data: bands, race countdown, sport totals, load.
2. Context shows itBrick only between two sport sessions. Triathlon plan only with a triathlon race.
3. Set values stay openRare options sit under "More options". It opens by itself when something is set.
4. One door per action"Add a session" offers a strength program or a swim, bike or run workout.
